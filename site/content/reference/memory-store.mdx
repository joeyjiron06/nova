---
title: MemoryStore
description: Keeps entries in a Map inside the current process. Works in every JavaScript runtime and needs no configuration.
---

`MemoryStore` is the default choice and the one that runs everywhere — Node, the
browser, Bun, Deno. It holds a `Map` of entries in the current process.

```ts
import Nova from "nova-cache";
import MemoryStore from "nova-cache/store/memory";

const cache = new Nova({
  store: new MemoryStore(),
  ttl: 60_000,
});
```

The constructor takes no arguments.

## What you get

**Nothing is serialized.** Values are held by reference, so a `Date` stays a
`Date`, a class instance keeps its prototype, and there is no encoding cost on
read or write. Any value is allowed, including ones that cannot be serialized at
all, such as functions and DOM nodes.

**Nothing is shared.** The map lives in one process. A second process, or a
second worker, has its own empty cache.

**Nothing survives.** Entries die with the process.

<Callout type="warn" title="Entries are not evicted on expiry">
  An expired entry is removed when something reads it, not when it expires.
  Caching a large number of keys that are never read again will hold onto memory.
  Call `clear()` if that matters to you.
</Callout>
